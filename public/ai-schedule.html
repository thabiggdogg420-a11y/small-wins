Your output contract
Use one line per activity: activity ID | start | end. Times use the 24-hour clock, for example activity | 09:00 | 09:20. Use the exact source IDs, without a header, bullets or code fences. Keep every duration. A new activity may start at the exact time the previous one finishes.
One person uses one room. Nothing can overlap. Gaps are allowed. Start with the flawed example if useful, but compare every constraint with the source.
This brief changes the fixed start, durations and where the break belongs. Start blank without the first answer in view. Optional help is recorded; this is practice, not proof of independent skill.
Anchor the fixed start first. Count backwards for anything that must finish before it, then forwards for later activities. End minus start must equal the full duration. Check every pair for overlap, not just neighboring lines. A gap is fine; making an activity shorter to squeeze it in is not.

2. Correct the plan, not the source facts
Move activities or use available gaps. Do not silently shorten the work, delete a break or move a fixed start to make the answer look right. If a real brief cannot fit, ask to change the scope or window instead. Record any extra AI or person help above.

3. Explain the check and keep a run sheet
The run sheet includes unallocated time and the constraints. It has no calendar date or time zone. A local check does not confirm actual durations, people, room availability, travel or real-world use. Nothing is sent, booked or added to a calendar.


Keep your evidence, even if unfinished
Download each task separately. Its record keeps the source, first submission, feedback, correction, request, checking note and help. It excludes the other task's answer. This is readable text, not an automatic resume/import file. Downloaded copies survive Clear.



Put the method to use
Plan one small thing of your own.
Use up to five harmless activity labels, such as “prepare materials”. One person, one room, one day. No names, addresses, personal appointments or private details. This planner is separate from the exercises and does not award learning credit.
Set honest durations and constraints, then enter your proposed start and end times. Blank rows are ignored only when every field in the row is empty. “After activity” means that activity must finish first. Allow time for setup, breaks and packing instead of assuming they happen for free.
