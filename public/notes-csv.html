01 · Set the source
What should the table contain?
Use 1–12 entries, one per line: ID | note. Give each entry its own short ID, even when items repeat. Keep each note to 500 characters; 7,000 total. Leading and trailing spaces around an ID or note are ignored; the reviewed source is shown below after checking.


IDs: letters, digits, underscores or hyphens, starting with a letter or digit; at most 24 characters. No blank lines inside the list. This field starts empty: the example above is only a placeholder.


Choose 1–5 different names, at most 24 characters each, using lowercase letters, digits and underscores. Start with a letter. source_id is always added first. Use columns actually supported by your notes, or leave missing values empty.

03 · Check the meaning yourself
Where did each value come from?
The local check covers CSV syntax, column order, source IDs, row coverage and formula-like text. It does not understand your notes or prove a value is true. Copy a short exact excerpt from that row's source and compare it yourself. Finding the excerpt in the note proves only that the text occurs there, not that it supports the value.
For an empty cell, check that the source really leaves that field unstated. If the source says 0, return to the CSV and write 0. If you correct any source, column or CSV text, run the check again and renew every comparison.
