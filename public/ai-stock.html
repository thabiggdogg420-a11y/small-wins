Your output contract
Use the four columns source_id, item, quantity, location, in that order. Each numbered note becomes one row. Keep the three-digit IDs as text, including their leading zeros. Repeated items stay separate because their source IDs differ. A missing quantity is an empty cell; a counted zero is 0. Keep the exact item and location labels.


A comma inside an item belongs in one cell: write “labels, large” inside straight double quotes in CSV. You can start with the prepared draft, but it deliberately contains mistakes. The checker compares parsed cells with this fictional source, not the appearance of the text.


Start this different task without the first answer in view. It adds a counted zero and quotation marks inside a label. Write your own request if using AI. Optional help is available; using it is fine and is recorded. This is practice, not a test of proven independence.


Count source IDs, not distinct item names. Leave an unknown quantity between two commas. Put a cell containing a comma or quote inside straight double quotes.
