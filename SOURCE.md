# Source baseline

This is a clean contributor export of Learn4Free public version 92, prepared from the exact released source commit 6a0611b9a299f31266a7d38c63a58e35e1e5f37b. All 114 browser assets are unchanged from that source. This export does not change or deploy the hosted site.

The export includes browser source, focused regression tests, synthetic regression fixtures, aggregate measurement source and schema migrations. It excludes private deployment configuration, production data, private review notes, browser acceptance receipts, unreleased preparation/server prototypes, generated historical builds and the host-specific browser harness.

Existing contributor documentation, MIT licensing and third-party notices are retained. The fictional job-application starter includes its own scoped MIT notice, which is preserved. Linked third-party applications, models and services are not included or relicensed.

The existing portable Worker builder uses a filesystem-safe URL conversion and writes schema source under dist/migrations/ without requiring hosting account metadata. This repository does not deploy automatically. A static preview does not provide the usage API; its absence does not prevent core browser practice.

Version 92 includes stock-list working JSON save/review/replace/revise/return with preserved first attempts and assistance history. Imported history is labelled unverified; current checks and approvals must be performed again. This is not proof of novice mastery, actual AI use, physical-mobile or assistive-technology acceptance.

Tests use synthetic fixtures and VM/DOM adapters. They do not replace rendered-browser or real-learner assessment. Historical public workflow acceptance is distinct from the contributor export checks.
